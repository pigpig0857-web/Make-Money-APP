# StockVision AI 智慧投資分析助理

台股真實行情研究儀表板：技術面 K 線、規則評分、基本面查詢與歷史資料儲存。籌碼資料尚未接入，未提供完整綜合投資評分。

## 功能模組

1. **股票搜尋**：股票代號、中文名稱與熱門標的切換。
2. **真實股價與歷史儲存**：Yahoo Finance 日 K、盤中報價與 PostgreSQL 儲存。
3. **技術分析**：日／週／月 K、均線、成交量、RSI、MACD、支撐壓力。
4. **技術評分**：真實已完成日 K 的趨勢與動能，滿分 60；不是勝率。
5. **基本面輔助**：Yahoo 查詢指標，缺少則顯示缺漏，不計分。
6. **真實法人資料**：證交所／櫃買中心近 20 個交易日買賣超與每日明細，標示缺漏；大戶、融資融券尚未接入。
7. **評分歷史**：保存實際行情、分數、規則版本及記錄時間，避免重複新增相同診斷。

## 資料來源

- 預設優先使用 **yfinance** 抓取 Yahoo Finance 即時資料。
- 外部行情取得失敗時，可顯示標示為過期的真實歷史行情，但不評分；無真實資料時顯示缺漏，禁止產生模擬行情。

## PostgreSQL 連線

已建立的資料庫名稱為 `Make Money APP`。

1. 將 `.streamlit/secrets.toml.example` 複製為 `.streamlit/secrets.toml`。
2. 在 `[postgres]` 區塊填入本機 PostgreSQL 帳號的密碼；如果 pgAdmin 使用其他主機、埠或帳號，也需同步修改。
3. 使用啟動 App 的 Python 執行 `python -m pip install -r requirements.txt`。
4. 啟動 App，在側邊欄展開「資料庫連線」，按「檢查資料庫連線」。

`secrets.toml` 已加入 Git 忽略清單，不應提交。

### 股價自動儲存

首次設定或升級時，在側邊欄按「初始化專案資料表」，或執行 `python -m backend.services.stock_repository`。
程式在 `money_app` schema 中使用 `stocks`（股票）、`daily_prices`（還原日 K 行情）、`price_downloads`（下載範圍及更新時間）、`institutional_flows`（法人歷史）及 `score_snapshots`（評分紀錄）。

搜尋及切換 K 線時，優先讀取 5 分鐘內更新的資料庫行情；沒有資料或已過期就抓取 Yahoo 並寫入。
同一股票、同一日期採更新方式，避免重複。日 K、週 K、月 K 要求的歷史跨度分別管理，避免長週期讀到不足的資料。
Yahoo 無法取得資料時，優先顯示明確標示更新時間的離線歷史行情；兩者都沒有時顯示資料無法取得，不產生模擬行情。
資料庫無法連線時，仍可使用真實外部資料分析，來源欄會標示儲存失敗。
側邊欄「查看已儲存資料」可查股票數、日 K 筆數及最後寫入時間。
搜尋時保存真實股價、官方法人資料及成功產生的評分；尚未啟用每日排程，因此沒有被搜尋的股票不會自動更新。

## 注意事項

本專案僅供教學與研究用途，所有數據與診斷結果均不構成投資建議；投資有風險，決策前請自行審慎評估。

## 真實資料評分範圍

正式 App 已停用模擬行情及模擬籌碼。當前評分為 `technical-real-v1`：60 日趨勢 30 分 + 7 日動能 30 分，總分 60。籌碼與基本面不計分；分數不是勝率，也不可與舊版 100 分直接比較。
至少需要 120 根已完成日 K，來源必須是 yfinance 或其資料庫行情。當天盤中日 K 不納入評分。過期資料僅展示，不提供操作建議。
固定景氣週期、缺貨、庫存與資本支出判斷已停用；Beta 與財務指標僅展示 Yahoo 查詢值，缺少則明確標示。
日 K OHLCV 可彙整週／月 K，但無法推算真實法人、融資融券、大戶與財報。`modules/`、`backups/` 僅保留舊程式，正式入口不使用。

## 法人與評分紀錄

上市使用 [證交所三大法人買賣超日報](https://www.twse.com.tw/zh/trading/foreign/t86.html)，上櫃使用 [櫃買中心三大法人買賣明細](https://www.tpex.org.tw/zh-tw/mainboard/trading/major-institutional/3itrade/day.html)。單位為股，外資包含外資自營商；自營商包含自行買賣與避險。程式檢查報表日期、格式與加總，不將缺漏轉為零。
只請求已完成行情的最近 20 個交易日；不足時顯示實際取得筆數及日期，不冒稱完整 20 日累計。成功資料會存入 `institutional_flows`，後續優先讀取；若官方修訂歷史報表，需另行重新抓取才能更新已存資料。目前法人作為輔助資訊，未加入 60 分技術評分。

`score_snapshots` 保存行情截至日期、實際記錄時間、規則版本、分數和完整行情輸入及診斷。完全相同的行情與診斷不重複新增；行情或診斷改變時新增紀錄，不覆寫舊紀錄。
記錄時間是系統實際產生診斷的時間，不能把今日算出的歷史行情評分當成當日已知的建議。歷史回測與實際評分後績效追蹤分別提供。

## 歷史回測

搜尋股票後，展開「歷史回測：技術評分規則」，設定資金、期間、成本並執行。
固定規則：前日技術分數 ≥45，隔日開盤進場；前日分數 <36、前日收盤觸發停損或達最長持有期限，隔日開盤退場。
一次一筆、使用全部試算資金、整數股數，不借款；期末按最後收盤價扣成本結算。
指標只用當時已有的日 K，前 120 根為暖身；策略與買進持有使用相同日期、成本及期末結算方式。
展示策略淨報酬、買進持有淨報酬、日收盤最大回撤、完成交易次數、勝率與交易明細。

成本預設為單邊手續費 0.1425%、一般股票賣出稅 0.3%、單邊滑價假設 0.05%，最低手續費預設 0 元；可依券商與商品調整。
參考 [證交所投資指南](https://www.twse.com.tw/zh/about/company/guide.html)、[ETF 交易制度](https://www.twse.com.tw/zh/products/securities/etf/overview/rules.html)；ETF、債券 ETF 等商品不能直接套用一般股票稅率。

使用 Yahoo 還原 OHLCV，沒有另外加入股利現金流；未模擬漲跌停、流動性限制與零股撮合。
停損在前日收盤判斷、隔日開盤執行，跳空可能擴大損失。最大回撤只按日收盤估值，未計入盤中極值。
規則尚未經過跨股票與樣本外驗證，不做歷史最佳參數搜尋。回測結果暫存在目前瀏覽工作階段，未寫入資料庫；原始行情仍會保存。

## 營收、產業與市場依據

搜尋後展開「營運與市場：真實資料診斷依據」，按「更新月營收與大盤比較」。
上市營收使用 [TWSE OpenAPI](https://openapi.twse.com.tw/) 的 `opendata/t187ap05_L`；上櫃使用 [TPEx OpenAPI](https://www.tpex.org.tw/openapi/) 的 `mopsfin_t187ap05_O`。
保存該市場整張報表，包含公司、官方產業、營收月份、出表日期、當月／上月／去年同月營收（新臺幣千元）、年增率、月增率、累計年增率及原始回應。
來源格式改變或數字缺漏時不造零；無資料的商品（例如 ETF）不給公司營收判斷。

`monthly_revenues` 按原始回應雜湊保留修訂版本，保存 `first_seen_at`、`last_seen_at`；相同版本不重複新增。
出表日期不是個別公司實際公告時間。現有 API 為最新月份報表，歷史月份只從實際觀察逐月累積，沒有歷史回填或三個月成長推算。
這些資料目前不用於歷史回測，也不直接增加技術分數；未來若納入模型，必須使用當時可知版本，不能按營收月份提前套用。
來源暫時失敗時使用有日期標示的資料庫離線營收；儲存失敗仍可顯示真實來源值，但會警示。

同業比較是同市場、同官方產業、同營收月份的其他公司營收年增率中位數，至少 3 家；不是產業股價指數，也不代表獲利或未來股價。
上市市場比較使用 Yahoo 的加權指數 `^TWII` 日 K，保存於既有行情表。
上櫃使用 [官方日成交量值指數](https://www.tpex.org.tw/zh-tw/mainboard/trading/info/daily-indices.html) 月報 `afterTrading/tradingIndex`，收盤指數另存 `market_index_closes`；沒有開盤資料就不補造，也不用於成交試算。官方最新交易日尚未公布時，日期不一致就暫不比較。
採最近 20 個股票交易日，同樣的起訖日期計算股票還原價格報酬與指數報酬及差值（百分點）。日期未對齊則拒絕計算。
未扣成本；股票還原價格與市場價格指數的股利處理不同，這不是可成交的對沖策略或風險調整超額報酬。
新功能只在按鈕提交時抓取，市場報表快取 1 小時；尚無每日自動排程或全市場股價更新。

## 評分後績效追蹤

展開「評分後的結果：5／20／60 交易日追蹤」，按「更新評分後績效」。
讀取最近最多 100 筆實際評分，起算點為評分記錄日（臺灣時區）與行情截至日之較晚日期後，第一個行情交易日的還原開盤。
即使評分記錄在盤前，也保守地從下一個交易日起算；不把歷史行情日當成當時已發出的評分。
第 5／20／60 個交易日收盤計算價格報酬、期間最低收盤相對起算開盤報酬。盤中當日日 K 及未來日期排除。
不足天數顯示等待；下載歷史未涵蓋記錄時間時顯示歷史不足，不擅自把起算日往後移。依 Yahoo 回傳的交易日列數計數，未另行校驗官方交易日曆。

已完成結果寫入 `score_outcomes`，含計算版本、起訖日、價格來源及輸入雜湊；相同評分／期間／版本採更新，保留評分原始快照。
後續 Yahoo 還原價格修訂時，更新追蹤可重新計算結果；它不是不可修改的成交紀錄。
報酬不扣費、稅、滑價，也不另列股利現金流；最低收盤報酬不是最大回撤、不是盤中最大跌幅。
同股票同日的多筆診斷及不同觀察期間可能重疊，不是獨立交易樣本；目前不計算綜合勝率或宣稱上漲機率。
資料庫登錄公司數包含整張營收報表的公司及市場指數，側邊欄另外顯示真正有日 K 的標的數。

## 電腦版追蹤清單與補齊資料

側邊欄「追蹤清單與補齊資料」可輸入股票代號／名稱，或把目前搜尋的股票加入清單。
`money_app.watchlist` 保存清單，重新開啟程式仍保留；移除清單不刪除股價、法人、評分或績效。
首次升級先初始化專案資料表。開啟後按「補齊追蹤股票資料」，才開始更新；沒有每日排程或登入自動更新。

可選 1／2／5 年 Yahoo 行情下載範圍與最近 20／60／120 個股票交易日的法人補齊範圍。
每檔重新下載該範圍真實行情並更新日 K，盤中當日日 K 與未來日期不寫入本次完成資料範圍。
法人依真實股票交易日期檢查，包括區間內缺洞，不只從最後一筆日期往後抓；已存在的日期跳過。
每批整張清單最多請求 60 份官方日報，預防初次大量補歷史阻塞或過度請求。達上限會顯示部分完成與缺漏日期，再次執行可繼續。
來源空報表、尚未公布、網路失敗或儲存失敗，均不造零；單檔失敗仍處理後續股票。
沒有歷史財報／月營收回填，也沒有把缺少日期事後建立為當日實際評分。未來若增加歷史重算，需獨立標示。

補齊後依實際評分快照更新已到期 5／20／60 日績效，最近最多 10,000 筆評分；超出行情範圍的記錄提示改選較長範圍。
結果表列出保存日 K 的起訖日期與總筆數、法人已具備／需具備數、缺漏日期、已到期績效數與錯誤。
重複執行採 upsert，不新增重複股票／日期紀錄；法人來源修訂的已存在日期不在此流程自動重抓。
執行中每次只處理一個小步驟，避免主畫面自動更新打斷；按停止會保留已寫入資料。
瀏覽工作階段中斷可繼續；關閉程式後新批次會依資料庫重新檢查。日 K 來源失敗且只剩離線資料時，不宣稱本次補齊成功。
