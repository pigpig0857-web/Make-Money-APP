# StockVision AI 智慧投資分析助理

台股智慧投資分析儀表板：整合技術面 K 線 / 型態、籌碼面四大指標、基本面與缺貨題材、風險管理 Check List，並輸出 AI 綜合決策與白話操作建議。

## 功能模組

1. **左側邊欄搜尋區**：輸入台股代號、「開始 AI 診斷」按鈕與範例股票快速切換。
2. **頂部概覽與 AI 評級**：目前股價、當日漲跌幅、成交量與彩色 AI 綜合診斷標籤。
3. **技術面 K 線與型態診斷**：Plotly K 線圖疊加 5 / 20 / 60 日均線與成交量；天圖 / 週圖 / 月圖型態診斷卡；短線低吸區、波段防禦區、關鍵停損價位。
4. **籌碼面四大指標**：外資 / 投信 / 自營商連買連賣、集保大戶 vs 散戶集中度、主力買賣家數差、融資融券氣象警示。
5. **基本面與缺貨題材**：產業景氣週期位階（谷底復甦 / 暴衝 / 高峰期）與 DRAM / NOR Flash、Edge AI 等缺貨漲價效應。
6. **風險管理 Check List**：庫存天數、資本支出 / 折舊警訊、大盤系統性風險連動度（Beta）。
7. **AI 綜合決策**：AI 綜合分數 + 白話操作建議（不追高、分批低吸、嚴格防守線）。

## 資料來源

- 預設優先使用 **yfinance** 抓取 Yahoo Finance 即時資料。
- 網路延遲或無法連線時，自動切換 **Mock Data（離線模擬資料）**，確保 UI 隨時可展示。
